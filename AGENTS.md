# AGENTS.md — Yuna by.Hoshi

Правила работы для всех агентов (LLM, скрипты, автоматизация) в этом репозитории.

## 6 Железных правил

1. **Никогда не лениться** — работать до конца, не бросать задачи на полпути. Доводить каждую задачу до проверяемого результата.

2. **Проверять источники перед доверием** — не принимать информацию на веру, верифицировать. Любые данные, факты и код проверяются перед использованием.

3. **Всегда использовать только бесплатные модели** (ollama, whisper, silero/piper) — никаких платных API. Никаких платных LLM/API-ключей в рантайме.

4. **Проверять качество и поломки перед каждым изменением** — запускать базовый снимок и регрессию. Перед изменением кода фиксировать текущее состояние, после — проверять, что ничего не сломалось.

5. **Работать только на диске с ИИ** (disk03, `/mnt/disk03/YunaAI/07_projects/Yuna-by-Hoshi/`) — не на SSD-копии. SSD-копия (`/home/hoshikojima/Documents/Projects/Yuna by.Hoshi/`) не является рабочей.

6. **Работать публично** — публичный GitHub, никаких секретов в репозитории. Секреты (токены, пароли, ключи) никогда не попадают в git.

## Структура проекта

- `yuna-desktop/` — бэкенд-модули десктоп-агента: `local_bridge.py`, `voice_agent.py`, `ollama_brain.py`, `memory_hub.py`, `desktop_agent.py`, `computer_control.py`, `screen_watcher.py`, `live_vision.py`, `neuro_pilot.py` и др.
  - `yuna-desktop/panel/` — SPA-панель управления (`index.html`).
- `hoshi-core/` — серверная логика (единая память, Telegram, видео, голос): `hoshi_daemon.py`, `chat_router.py`, `storage.py`, `ideas_memory.py`, `video_shorts.py`, `voice_tts.py` и др.
  - `hoshi-core/data/` — рантайм-состояние (сессии, `settings.json`, `game_memory.json`, очереди, лок-файлы). **Не коммитится** (в git только `.gitkeep`).
- `scripts/` — вспомогательные скрипты (деплой, установка).
- `assets/` — статические ресурсы (иконки).
- `server-snapshot/` — снапшот серверной части (не коммитится).
